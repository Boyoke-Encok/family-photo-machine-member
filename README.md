A program that draws one family photo with a machine member: an afternoon at home — a mother on the sofa with a mug, a father at the counter chopping a half-peeled carrot, a child playing with wooden blocks on the rug, and one small household robot rolling in mid-task with a tray. The image is drawn procedurally with Python (Pillow): no network, no downloaded assets, no text in the frame.

## Run it

```sh
python3 main.py
```

This writes the 1024×1024 PNG to `/output/entry.png` (deterministic: the same bytes on every run).
